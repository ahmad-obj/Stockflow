# StockFlow

StockFlow is the SDA Warehouse & Supplier MIS. Use the submitted D2 proposal, D3 use cases, D4 domain model and system sequence diagrams, and D5 design class and sequence diagrams as implementation references. The SDA Project sources hold these documents. The AKD TradeCast assignment is a separate project.

- Use JavaFX for the presentation tier, plain Java for the business tier, and Oracle SQL with JDBC for the data tier. Keep domain classes independent of JavaFX and JDBC.
- Follow the submitted D5 class responsibilities and D3 workflows. Surface material discrepancies before implementing the affected behavior.
- Use the Maven Wrapper and keep the repository importable as an existing Maven project in Eclipse.
- Keep credentials in local environment variables. Use a dedicated Oracle schema for the application.
